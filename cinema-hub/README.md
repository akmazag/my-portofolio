# 🎬 CINEMA HUB

**Enterprise Internal Operation & Knowledge Management Portal**
*One Platform. One Knowledge. One Operation.*

Portal internal terpusat untuk operasional bioskop — jadwal film, upcoming movies, promo, layout akses publik
(bioskop & mall), pusat edukasi, direktori karyawan, problem & solving, dan pengumuman — dibangun di atas
**Google Apps Script + Google Sheets + Google Drive**.
